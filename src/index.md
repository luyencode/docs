## Hỗ trợ

Nếu có thắc mắc, vui lòng tạo issue tại [GitHub Issues](https://github.com/luyencode/lcoj-docker/issues).

**Cần hỗ trợ cài đặt?** Nếu bạn quá mệt mỏi để tự mình cài đặt, LCOJ sẽ hỗ trợ bạn cài đặt miễn phí. Liên hệ tại [behitek.com](https://behitek.com) hoặc [luyencode.net/about/#lien-he](https://luyencode.net/about/#lien-he).

Các ví dụ bài tập thực tế nằm trong thư mục [problem_examples](https://github.com/luyencode/docs/tree/master/problem_examples).
